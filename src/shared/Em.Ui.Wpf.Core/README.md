# Em.Ui.Wpf.Core

WPF UI components for Em System desktop applications. The package includes navigation and account screens, dialogs, themes, custom controls, PDF viewing, and release-management components. It is a UI library; the `Em.Ui.Wpf` application host is separate.

## Compatibility

Targets .NET 10 for Windows (`net10.0-windows`) and requires WPF. Depends on `Em.Libs` and `Em.Ui.Core`.

## Install

```sh
dotnet package add Em.Ui.Wpf.Core --prerelease
```
