# Em.Ui.Core

Shared UI and API-client foundation for Em System applications. It provides navigation contracts, API client and session handling, UI models, branding, themes, and claim-aware navigation logic. The WPF and MAUI UI packages build on this package.

## Compatibility

Targets .NET 10 (`net10.0`). Depends on `Em.Libs`.

## Install

```sh
dotnet package add Em.Ui.Core --prerelease
```
