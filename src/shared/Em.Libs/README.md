# Em.Libs

Shared contracts and utilities used by the Em System API and UI packages. This package contains common models, service interfaces, result types, UI identifiers, and Argon2 string hashing.

## Compatibility

Targets .NET 10 (`net10.0`). The API, WPF, and MAUI packages depend on this package.

## Install

```sh
dotnet package add Em.Libs --prerelease
```
