# Em.Api.Core

Server-side core for Em System. It provides API service registration, action routing and authorization, authentication services, and database access for Microsoft SQL Server, MySQL, and PostgreSQL. This is a library; the `Em.Api` HTTP host is a separate application.

## Compatibility

Targets .NET 10 (`net10.0`) and uses the ASP.NET Core shared framework. Depends on `Em.Libs`.

## Install

```sh
dotnet package add Em.Api.Core --prerelease
```
