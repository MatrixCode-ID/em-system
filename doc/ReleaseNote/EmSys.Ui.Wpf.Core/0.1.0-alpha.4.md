# EmSys.Ui.Wpf.Core 0.1.0-alpha.4

Date: 2026-10-06
Previous: 0.1.0-alpha.3

## Summary
The Container Publish tab now builds the image tag from a version and a channel, and numbers pre-release builds automatically from the tags the registry already holds.

## New features
- Publish (Container): a version spin edit (`A.B.C`) and a channel combo (`prealpha`, `alpha`, `beta`, `rc`, `release`) in the operation row, before Check. The chosen version and channel are saved in the profile and shown on the TARGET card.
- Publish (Container): on a pre-release channel the build number `N` is not typed. It is taken from the registry tags and the local history (highest existing number + 1, and back to 1 when the version or channel changes), giving tags such as `0.1.0-alpha.4`. The `release` channel uses the plain `A.B.C` tag, and Push is refused when that tag already exists.
- `ContainerVersion` (namespace `Em.Ui.Wpf.Publish`): parses and builds container version tags as described in the container naming convention. Tags it does not manage, such as `dev`, are left alone.
- `OciClient.Tags` returns the tag list of a repository; `LatestTag` now uses it.
- A themed horizontal scrollbar style for the operation strip, so a narrow window scrolls instead of rearranging the buttons.
