# EmSys.Ui.Wpf.Core 0.1.0-alpha.19

Date: 2026-10-30
Previous: 0.1.0-alpha.18

## Summary
Add the ImageComposer control for arranging images and arrows on a millimeter canvas and exporting a PNG, and rebuild the User Manager list around server-side search, filters, sorting and role badges. Fix the caller identity sent while a session is bootstrapped after simulated sign-in, and accept a standalone Android workload in Release Manager.

## New features

- `ImageComposer` (namespace `Em.Ui.Wpf.Controls`) with `ImageComposerVm` places multiple images and arrows on a white canvas measured in millimeters and exports a single PNG at a configurable resolution (default 300 dpi). It supports insert and paste of common image formats, selection and arrangement, canvas size inputs, read-only mode, an optional themed toolbar with commands still available to the screen, a 25–800% zoom slider, Ctrl+mouse wheel zoom at the pointer, middle-mouse panning and fit to view (Ctrl+0). Zoom and pan are view state only and never mark changes or affect the exported image. See `doc/engine/engine-image-composer.md`.
- User Manager uses `PostGetMeta_UserListPage` for the list: debounced search with a clear button, status segments synchronized with a filter sheet (draft with Apply, Reset and Escape), removable condition chips, sortable column headers, and role badges (ADMIN plus up to two named roles and a "+N" counter).
- Reload requests made while a load is running are queued instead of dropped, and the loading overlay covers only the rows so the search box keeps focus.
- Shared `FilterOption`, `ActiveFilterChip` and `ColumnSortState` types are available for building filtered and sortable lists.

## Fixes

- After a simulated sign-in, cached API clients are refreshed before the session profile loads, so requests no longer carry the debugger identity without its debug token. A failed profile load rolls back the session.
- Release Manager accepts a standalone Android workload installation and lists the specific environment components that are still missing.
- User Manager columns have consistent cell spacing, capped name and email widths, a flexible roles column that wraps chips, and theme-aware toggle text in the dark theme.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.19` and deploy the matching `EmSys.Api.Core` backend; the new User Manager list requires `PostGetMeta_UserListPage`.
- `ImageComposer` needs no server service, database migration or permission registration; the hosting screen owns validation and persistence of the exported PNG.
- No database migration is required relative to `0.1.0-alpha.18`.
