# EmSys.Ui.Wpf.Core 0.1.0-alpha.15

Date: 2026-10-22
Previous: 0.1.0-alpha.14

## Summary
Container Manager can add a tag to an existing manifest, and the remaining raw context menus and system message boxes now use the Em style.

## New features

- Container Manager: an **Add tag** icon on each manifest card, before Copy digest, asks for the tag and points it at that manifest without a push (for example `latest` or `1.0.0` on a manifest pushed as `1.0.0-beta.4`). When the tag is already on another manifest, a **Move Tag** confirmation names that manifest (short and full digest) before the tag moves. Image index manifests can be tagged too. Deleting a tag is unchanged: right-click the tag chip, then **Delete tag**.
- `CtnInput.IsValidTag` checks a tag against the OCI tag rule, so the dialog rejects an invalid tag before calling the server.
- `CtnService.PostMeta_CtnTagAdd` calls the new action of EmSys.Api.Core.

## Fixes

- Seven context menus (Container Manager, the connection settings dialog, and the generic theme) used the plain WPF menu; they now use `cascadeContextMenuStyle` and open at the mouse pointer.
- The publisher, NuGet Manager, and the storage settings card showed the system message box; they now show `EmMessageBox`, which follows the theme.

## Upgrade notes

- Add tag requires an API built on EmSys.Api.Core 0.1.0-alpha.15. An earlier API answers 404 for the action.
