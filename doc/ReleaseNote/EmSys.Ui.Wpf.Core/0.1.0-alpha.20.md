# EmSys.Ui.Wpf.Core 0.1.0-alpha.20

Date: 2026-11-01
Previous: 0.1.0-alpha.19

## Summary
Show QR codes on the desktop: the engine registers `IQrCodeService`, `QrCodeImage` turns a text into a frozen `BitmapSource`, and the themed `QrCodeView` control draws a scannable code from XAML in light and dark themes.

## New features

- `IQrCodeService` is registered by the engine in every WPF host; resolve it from `EmApp.ServiceProvider`.
- `Em.Ui.Wpf.Shared.QrCodeImage`: `Create(text, options, service)`, `FromPng(png)` and `ToQrColor(brush, fallback)`.
- `Em.Ui.Wpf.Controls.QrCodeView` with `Text`, `Size` (default 160), `ErrorCorrection` (default M) and `QuietZoneSize` (default the standard 4-module quiet zone; a width replaces it with a thinner border). Colors come from the theme window tokens; the lighter one is always the tile and quiet zone, so the code stays dark on light in a dark theme. The image is redrawn for the screen DPI and on theme changes; text that cannot be encoded shows an empty tile with the reason in `Error`.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.20` together. No database migration is required. See `doc/engine/engine-qr-code.md`.
