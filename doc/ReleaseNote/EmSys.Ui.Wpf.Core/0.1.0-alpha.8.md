# EmSys.Ui.Wpf.Core 0.1.0-alpha.8

Date: 2026-10-09
Previous: 0.1.0-alpha.7

## Summary
Adds the SMTP Manager screen under Administrative Tools, two new shared input styles (an editable combo box and a framed date field), and tidies the User Editor: account names are typed in lower case and the unfinished Activity tab is hidden.

## New features

- **SMTP Manager** (navigation `admin.smtp`, claim `Administrative Tools:SMTP Manager Access`): a table of SMTP profiles with New, Edit (also by double-click), Delete, Set/Clear default and Refresh; a side-sheet editor for the connection settings only (no sender); and a test toolbar where you pick a saved profile, enter From and To, and send a test email. The test choice is independent of the selected row and the default. The menu entry appears only when the server enables SMTP.
- From and To in the test toolbar remember up to 20 addresses each, newest first, after a successful send. The history is stored under the host application's `BaseRegKey` (subkey `SmtpManager`); Clear history removes only these values.
- `ISmtpService` and `ISmtpProfileService` are registered automatically with the proxies from `EmSys.Ui.Core`.
- Style `fieldEditableComboStyle`: an editable `ComboBox` with the same frame and popup as `fieldComboStyle`.
- Style `fieldDatePickerStyle`: a `DatePicker` with the same frame, height and states as `fieldBoxStyle`, so date fields line up with text fields.

## Fixes

- User Editor: the Account field turns typed and pasted text into lower case; an existing value stays as stored until it is retyped.
- User Editor: the Activity tab, which only showed sample data, is hidden and cannot be reached with the keyboard.
