# EmSys.Ui.Wpf.Core 0.1.0-alpha.17

Date: 2026-10-23
Previous: 0.1.0-alpha.16

## Summary
CDN Manager gets folder settings, hidden files, Rename and Copy. Release Manager hides release folders from the public listing, treats the CDN address as a base, adds a manual launcher build and fixes Prepare for hosts with referenced libraries. Dialogs open centred on their owner.

## Breaking changes

- The release profile CDN address is now the CDN base only (for example `https://host/cdn/`); `ReleaseTarget.ReleaseAddress` appends the release folder for Compare, Verify and the launcher source. A profile that stored the address of the release folder itself must be changed to the base.
- `EmWindow` defaults `WindowStartupLocation` to `CenterOwner` (the screen centre without an owner). Windows that place themselves must set `Manual` explicitly.

## New features

- CDN Manager: a Folder Settings dialog (public listing, hidden/shown patterns, Export; read-only in managed folders), a Show hidden files toggle with a marker on hidden entries, Rename (F2) and Ctrl+drag Copy running as a server task.
- Release Manager turns the public listing off for the release folder, `binaries/` and every subfolder when a folder is managed and after each Sync, through the new `ReleaseTarget.CompleteSyncAsync`.
- Release Manager: a Build launcher command that rebuilds even when the inputs are unchanged (Prepare still builds only on changed inputs), an Open launcher folder menu, and separate cards for the application icon and the logo in Release settings.
- `EmApp.LastDebugProfileName` remembers the connection picked while debug is active; `PreferredDebugConnection` falls back to the default debug connection and is used at startup, on the multi-tab toolbar and on the home card, which now follows active connection changes made elsewhere.
- While debug is active, the debug token is sent through every connection; Simulate Login takes it off and puts it back when the simulation ends.

## Fixes

- Prepare applies the product identity to the host project only, through a generated targets file. Before, global properties renamed every referenced library after the host and restore failed with an ambiguous project name.
- Release settings no longer reads the solution on open or on the UI thread; host projects are read in the background with progress, and Browse or Check solution lists them again. Save/Cancel stay fixed above the scrolling form.
- Compare stops with a clear error when the server has a release in the release folder but the public CDN address answers 404, instead of uploading everything again on each Sync.
- `LauncherIntegration` finds the installation root from the single `app` folder used by the current launcher as well as from older versioned folders.

## Upgrade notes

- Requires an API on EmSys.Api.Core 0.1.0-alpha.17 for folder settings, Rename and Copy; earlier APIs answer 404.
- Check each release profile's CDN address after updating (see Breaking changes).
