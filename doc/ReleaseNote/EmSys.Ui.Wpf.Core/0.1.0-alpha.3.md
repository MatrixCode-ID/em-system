# EmSys.Ui.Wpf.Core 0.1.0-alpha.3

Date: 2026-10-06
Previous: 0.1.0-alpha.2

## Summary
Container Manager gains garbage collection, tag and manifest deletion, and a marker for images with missing blobs. The Publish tab gains encrypted profile export/import, a per-credential HTTP option, and help for Docker insecure-registries.

## Breaking changes
- NuGet Manager no longer appears as a group in the Tools/Administrative menu (`IsMenuVisible=false`); the screen can still be opened through the `admin.nupak` navigation. Hosts that relied on that menu entry must provide their own way in.

## New features
- Container Manager: a Garbage collection button with a review dialog (dry run, then Run), delete tag from the right-click menu of a tag chip, and delete manifest from the icon or right-click menu of a manifest row.
- Container Manager: images with missing blobs are flagged with a red chip, a banner, an icon in the tree, and a warning per manifest.
- Publish: profile export with three options (without secrets, encrypted with a passphrase, or plain text) and an import that restores secrets. Encrypted files use the `.ctnconfig` (Container) or `.nugetconfig` (NuGet) extension, with AES-256-GCM and PBKDF2-SHA256.
- Publish: an Allow Http option per credential for registries without TLS, applied to the application's own verify and tag-discovery requests.
- Publish: the Docker check reads `docker info` and warns about HTTP hosts that are not yet insecure registries, or `localhost` on Docker Desktop. The More menu offers "Add registry to Docker insecure-registries" (edits `daemon.json` after making a backup).

## Fixes
- The error for a missing credential names the destination host and the hosts the profile does have credentials for, which makes a credential saved for the wrong host easy to spot.
- The Publish status message is shown as a full-width strip below the operation buttons and disappears when empty.

## Upgrade notes
- After adding a host to insecure-registries, restart Docker Desktop.
