# EmSys.Ui.Wpf.Core 0.1.0-alpha.16

Date: 2026-10-22
Previous: 0.1.0-alpha.15

## Summary
On/off switches for the storage services, an inline CDN file size editor, and menus that follow the features the server offers.

## New features

- `FeatureServiceToggle`: the CDN, NuGet, Object Storage and Container Manager screens show a switch for their service. Holders of the manager claim see the state; only administrators can change it, and the change applies at once.
- CDN Manager: the Settings card is replaced by a pencil on the file size chip with an MB box and Save/Cancel. Managed folders keep their quota without a pencil.

## Fixes

- The claim catalog uses `NavigationAccess.MergeClaimCatalogs`: a storage manager whose feature the server does not declare is hidden from the home menu and cannot be opened directly.

## Upgrade notes

- Requires an API on EmSys.Api.Core 0.1.0-alpha.16; earlier APIs answer 404 for the new switch and limit actions and do not declare the Container Manager claims.
