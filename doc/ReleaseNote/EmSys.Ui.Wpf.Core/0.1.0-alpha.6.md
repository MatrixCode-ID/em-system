# EmSys.Ui.Wpf.Core 0.1.0-alpha.6

Date: 2026-10-08
Previous: 0.1.0-alpha.5

## Summary
The user editor in User Manager gets a Roles tab with a switch, an optional start and expiry date, and a search box for every role. Debug builds add Switch User and Simulate Login, and new `EmApp` properties separate showing debug features from skipping permission checks. Tab titles in the multi-tab window are no longer cut off when a tab is selected.

## Breaking changes

- In a debug build, Sign Out is hidden from the account menu and `SignOutAsync` does nothing while debug is active, because the debugger account never signed in. Use Simulate Login to test signing in and out.
- Client-side permission checks in the engine (`EmApp.CanOpen`, Approval Manager, Business Task Manager) now skip the check only when `EmApp.IsDebugBypass` is true, instead of whenever `IsDebugMode` is true. Module code that skips its own permission checks with `IsDebugMode` keeps compiling but ignores Switch User; change it to `IsDebugBypass`. Code that shows a debug-only feature should check `IsDebugActive`.

## New features

- The user editor replaces the unfinished Access tab with a **Roles** tab: one card per role with a switch, optional **Start** and **Expiry** dates, the number of permissions it carries, and `INACTIVE`, `SCHEDULED`, or `EXPIRED` chips. Role changes are saved with the record's **Save** button, including for a user that has not been saved yet. System accounts are shown locked.
- A search box on the Roles tab narrows the cards by role name or description and shows how many roles match. Hidden cards keep their changes, and **Save** still sends them.
- `EmApp.IsDebugActive` (a debug build that is not simulating a login), `EmApp.IsDebugBypass` (debug is active and the active user is the debugger account), `EmApp.IsSimulatingLogin`, and the `DebugStateChanged` event.
- **Tools > Switch User** (debug only) makes another stored account, or the built-in administrator, the active user without a password. Open screens are closed, requests carry the account's identity, and menus follow that account's real permissions. The choice is not remembered after a restart.
- **Tools > Simulate Login** (debug only) runs a debug build as without debug in the same process: no debug token, real password login, and nothing about the session is stored. A `SIMULATED` chip and a link on the login screen lead back to the debugger.

## Fixes

- In the multi-tab window, a tab title that grows after the tab is laid out (a selected tab turns semibold, or the title changes) is no longer cut off with an ellipsis. Only tabs that are shrunk to fit the strip are trimmed.
- The remaining Indonesian messages in the publisher are now in English.

## Upgrade notes

- Search module code for `IsDebugMode` used to skip permission checks and change it to `IsDebugBypass`. See the [debug mode guide](../../engine/engine-debug-mode.md).
- Switch User needs a server that accepts the debug token; no database migration is required for this release.
