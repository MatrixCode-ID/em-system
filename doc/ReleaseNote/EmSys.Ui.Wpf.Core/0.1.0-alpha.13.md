# EmSys.Ui.Wpf.Core 0.1.0-alpha.13

Date: 2026-10-21
Previous: 0.1.0-alpha.12

## Summary
Rebuilds the Approval Manager for the redesigned engine with a System Approval editor, decision dialog and signer settings, adds the Business Module Manager, Employee Editor and a shared Contact Picker, and extends the Release Manager with managed CDN targets, product launcher builds, embedded host identity and cabinet distribution.

## Breaking changes

- The approval client follows the new EmSys.Libs contracts; screens and modules built on the old approval panels must move to `ApprovalEditorRegistry`.
- Release Manager signing keys are stored with the release profile; the separate signing-key destination dialog and the old signing-secret helpers are removed.

## New features

- Approval Manager with the full request list, sub-summary, comments and attachments, plus `ApprovalDecisionDialog`, `ApprovalEditor` and `ApprovalSignerSettings` screens.
- Business Module Manager (tenants, department tree, employees) and an Employee Editor navigation that other screens can open with `EmployeeNavigationPayload`. Employee search covers all contacts.
- `ContactPickerDialog`: a shared contact picker with caller-supplied filters and selection rules.
- Role Manager: permission search; claims outside the server catalogue are kept.
- CDN Manager: recycle bin, temporary cleanup, managed folders and quota.
- Container Manager hides untagged manifests by default (`Show untagged`), and the WPF builder's `EnableContainerManager = false` hides the screen and refuses direct navigation, also in debug mode.
- Release Manager: publish to managed CDN folders, build product launchers from JSON profiles, signed launcher metadata, verified update preparation through the launcher, and LZX cabinet download with incremental reuse and offline installation.
- Host identity from MSBuild: the package's `buildTransitive` targets embed `EmAppId`, `ApplicationIcon` and `EmAppLogo` (PNG) into WPF executables.

## Fixes

- The Approval Manager grid no longer flashes white while loading.

## Upgrade notes

- Requires an API built on EmSys.Api.Core 0.1.0-alpha.13 with the approval database upgrade applied.
