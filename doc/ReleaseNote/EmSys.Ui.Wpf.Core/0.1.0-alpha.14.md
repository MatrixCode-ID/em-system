# EmSys.Ui.Wpf.Core 0.1.0-alpha.14

Date: 2026-10-21
Previous: 0.1.0-alpha.13

## Summary
Fixes publish profile export and checking, shows publish previews in a read-only dialog, offers project values for the Template build fields, and lets a deploy target choose how the image is written into the compose file.

## New features

- Publish profile editor: Configuration, Runtime and Framework of a Template profile are editable combo boxes filled from the project (its configurations, its runtime identifiers followed by the Linux ones, its target frameworks). A value outside the list can still be typed. `ProjectReader.Options` and `ProjectOptions` expose the same values.
- Project information, the generated Dockerfile and the file set preview open in a read-only `PreviewDialog` with Copy and Close, instead of an editable text box.
- Deploy target dialog: **Image in the compose file** for Stack targets, with image name (tag and digest, the default for new targets), image name (tag only) or image variable. The image variable field applies only to the variable choice. See EmSys.Api.Core for the deploy behaviour.
- Deploy target dialog: picking an environment or a stack runs Test connection again, so the stack and service lists follow the choice. A picker with nothing to offer is disabled and says to run Test connection.

## Fixes

- Export writes the profile workspace relative to the folder of the exported file (empty when it is on another drive), so an exported profile imports correctly from where it is stored. Before, it always wrote `.` and the import resolved paths under the folder of the file.
- Check verifies that the project and existing Dockerfile (Template), the Dockerfile and build context (Dockerfile) or the compose file and project directory (Compose) exist under the workspace, and names the full path it looked for (`Publisher.CheckSources`). Before, a wrong workspace passed Check and failed later in Build.
- The deploy target dialog keeps the service and container lists of the last test instead of older ones, and no longer draws a dotted focus rectangle around its form.

## Upgrade notes

- Requires an API built on EmSys.Api.Core 0.1.0-alpha.14 with its database update applied, because the deploy target now sends the image choice.
- Profiles exported by an earlier version still carry `"workspace": "."`; set the workspace again after importing them, or export them again with this version.
