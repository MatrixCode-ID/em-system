# EmSys.Ui.Wpf.Core 0.1.0-alpha.21

Date: 2026-11-14
Previous: 0.1.0-alpha.20

## Summary
The Business Module Manager moves to a left drawer with Organization, People, Attendance and Products folders, and gains positions, head of department, contact attachments, attendance setup and product setup. In active debug the Apps menu no longer depends on the server.

## New features

- Business Module Manager drawer tree replaces the tab strip: Organization (Tenants, Departments, Positions), People (Employees), Attendance (Scheduling settings, Schedule templates, Attendance codes, Public holidays) and Products (Units, Product types, Products).
- Employee Editor: position from the tenant positions, department head, contact full name and contact attachments.
- Products page: a tree read one level at a time, with a type filter, search, Add children and Copy children dialogs and a node context menu.
- A reusable decimal spin box and the Copy attendance codes dialog.
- Home and the Apps menu sort items by order index, then title, with groups alphabetical.

## Fixes

- Active debug without Simulate Login builds the Apps menu from the client registrations, loads claims only when a module opens, keeps the menu across server switches and simulation, and ignores claim responses from a previous server.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.21` together. The document controls (MatrixGrid, MatrixSheet, MatrixWriter) are in the new package `EmSys.Ui.Wpf.Controls`.
- Guides: `doc/engine/engine-business-module-manager.md` and `doc/engine/engine-debug-mode.md`.
