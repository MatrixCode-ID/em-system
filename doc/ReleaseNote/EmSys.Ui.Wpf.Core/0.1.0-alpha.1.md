# EmSys.Ui.Wpf.Core 0.1.0-alpha.1

Tanggal: 2026-10-06
Sebelumnya: —

## Ringkasan
Rilis pertama `EmSys.Ui.Wpf.Core` di nuget.org: komponen UI WPF untuk aplikasi desktop EmSys, siap dipasang di host WPF bersama `EmSys.Ui.Core`. Ini rilis alpha; API masih bisa berubah tanpa pemberitahuan di versi berikutnya.

## Isi paket
- Layar login bergaya Material (default) atau Classic, mengikuti tema dan branding.
- Navigasi SPA dan home screen default untuk host.
- Layar manager untuk administrator: User Manager (user dan robot), Role Manager, Approval Manager dan daftar tugas, Container Manager, NuGet Manager (NuPak), CDN Manager, serta Release Manager dengan profile.
- Publisher bersama untuk NuGet dan container (tab Publish beserta history).
- PDF viewer.
- Style dan kontrol bersama bertema terang/gelap (`Styles/MaterialDesign.xaml`), termasuk ListBox dan TreeView yang tetap bertema saat disabled.

## Catatan pemakaian
- Target `net10.0-windows` dan membutuhkan WPF. Bergantung pada `EmSys.Libs` dan `EmSys.Ui.Core` versi yang sama.
- Namespace tetap `Em.Ui.Wpf.Core`, berbeda dari nama paket `EmSys.Ui.Wpf.Core`.
- Fitur manager membutuhkan fitur pasangannya aktif di server (`EmSys.Api.Core`) dan claim yang sesuai pada user.
- Paket ini library; host aplikasi (`Em.Ui.Wpf`) tidak dirilis sebagai paket.
- Pasang dengan `dotnet package add EmSys.Ui.Wpf.Core --prerelease`.
