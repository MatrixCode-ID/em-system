# EmSys.Ui.Wpf.Controls 0.1.0-alpha.21

Date: 2026-11-14
Previous: —

## Summary
First release of the Em System WPF controls: the MatrixGrid data grid, the MatrixSheet spreadsheet editor, the MatrixWriter word-processing editor, a read-only document viewer, value editors and print preview, all following the active Em theme.

## Package contents

- `MatrixGrid`: a virtualized data grid with sorting, filtering, search and finder, grouping, summaries, in-place editing (with a cancelable `BeginningEdit`), two-way `SelectedItem`/`SelectedItems`, row commands and `RowDoubleClickCommand`, conditional cell presentation, layouts, context menus, print preview and export to PDF, XLSX, DOCX and CSV.
- `MatrixSheet`: a spreadsheet editor with formulas, formatting, merges, frozen panes, CSV and XLSX.
- `MatrixWriter`: a word-processing editor with paged layout, tables, headers and footers, DOCX and PDF.
- `DocumentViewer`: a read-only viewer registered by `UseDocuments()`; `NavigationEntry.ViewDocument(...)` opens XLSX and CSV in MatrixSheet, DOCX in MatrixWriter, and PDF in the PDF viewer.
- Standalone and in-cell value editors (`TextEditor`, `SpinEditor`, `DateEditor`, `CheckEditor`, `ComboEditor`, `LookupEditor`) and `PrintPreviewWindow`.

## Usage notes

- Target `net10.0-windows`. Depends on `EmSys.Libs`, `EmSys.Ui.Core` and `EmSys.Ui.Wpf.Core` of the same version.
- Install: `dotnet add package EmSys.Ui.Wpf.Controls --prerelease`.
- Call `builder.UseDocuments()` in the WPF host so the controls follow the active Em theme; without an Em host they use their built-in Light and Dark palettes.
- All WPF types are in the namespace `Em.Ui.Wpf.Controls`, with the XAML namespace `https://MatrixCode/wpf/controls` (prefix `emc`). Engine types such as `GridColumn` come from `EmSys.Libs` through `clr-namespace` (`Em.Controls.Grid`).
- Third-party notices are in `THIRD-PARTY-NOTICES.md` and `licenses/` inside the package. Guide: `doc/engine/engine-documents.md`.
