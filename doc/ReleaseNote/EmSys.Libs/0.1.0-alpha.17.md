# EmSys.Libs 0.1.0-alpha.17

Date: 2026-10-23
Previous: 0.1.0-alpha.16

## Summary
Contracts for CDN folder settings, Rename and Copy, plus a hidden marker on CDN entries.

## New features

- `CdnFolderSettings` and `CdnFolderSettingsFormat`: the settings of one CDN folder, kept in a hidden `.meta` file per folder. `PublicListing = false` makes the public listing of the folder answer 404 and marks its files as not to be indexed; `HiddenFiles`/`ShownFiles` patterns leave entries out of the public listing while direct links keep working. `Parse`, `Serialize`, `Validate`, `IsHidden` and `Matches` share one format and its limits (version 1, at most 64 KB, 256 patterns of 255 characters).
- `ICdnServices` (claim CDN Manager Access): `GetMeta_CdnFolderSettings`, `PostMeta_CdnFolderSettingsSave` and `GetMeta_CdnFolderSettingsExport` read, replace and export folder settings (`CdnFolderSettingsDetail`, `CdnFolderSettingsSave`); `PostGetMeta_CdnRename` renames within a folder; `PostGetMeta_CdnCopy`, `GetMeta_CdnCopyTask`, `PostMeta_CdnCopyCancel` and `PostMeta_CdnCopyClear` copy a file or folder as a business task (`CdnCopyRequest`).
- `ICdnReleaseServices.PostMeta_CdnReleaseFolderSettings` (claim Release Manager Access) replaces folder settings inside the root a product owns (`CdnReleaseFolderSettingsRequest`).
- `CdnEntry.IsHidden`: `true` when the containing folder's settings leave the entry out of the public listing.

## Upgrade notes

- The new actions are served by EmSys.Api.Core 0.1.0-alpha.17; earlier APIs answer 404.
