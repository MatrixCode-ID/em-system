# EmSys.Libs 0.1.0-alpha.14

Date: 2026-10-21
Previous: 0.1.0-alpha.13

## Summary
Adds the choice of how a Stack deploy target writes the image into the compose file: the image name with tag and digest, the image name with tag only, or the image variable.

## New features

- `CtnDeployImageRef` (`Variable`, `TagDigest`, `Tag`) and the `ImageRef` property on `CtnDeployTargetInfo` and `CtnDeployTargetSave`. On save, `null` keeps the stored choice; a target saved without one uses `Variable`.
