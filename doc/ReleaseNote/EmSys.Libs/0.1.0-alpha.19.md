# EmSys.Libs 0.1.0-alpha.19

Date: 2026-10-30
Previous: 0.1.0-alpha.18

## Summary
Add the contract for a server-side user list query that searches, filters, sorts and pages users in one call and returns the roles each user currently holds.

## New features

- `ICredentialServices.PostGetMeta_UserListPage(UserListQuery)` returns a `UserListPage` with the requested rows, the total record count and the roles in effect for those rows (`UserListRole`).
- `UserListQuery` carries the page, page size (default 200), sort field (`UserListSortField`) and direction, and a `UserListFilter` with free-text search, user states, role ids, admin-only and include-deleted options. The backend is supplied by `EmSys.Api.Core`; client proxies by `EmSys.Ui.Wpf.Core` and `EmSys.Ui.Maui.Core`.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.19` together. No database migration is required relative to `0.1.0-alpha.18`.
