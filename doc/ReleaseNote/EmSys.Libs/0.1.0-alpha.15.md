# EmSys.Libs 0.1.0-alpha.15

Date: 2026-10-22
Previous: 0.1.0-alpha.14

## Summary
Adds the contract for putting a tag on a manifest that is already in a container, without pushing the image again.

## New features

- `ICtnServices.PostMeta_CtnTagAdd(imageId, manifestId, tag)` points a tag at an existing manifest of the container. A tag points at one manifest per container: when it is already on another manifest, it moves to the chosen one. It does not start a deploy. The server answers 400 for a tag that is not a valid OCI tag and 404 when the container or manifest is missing. Implemented by EmSys.Api.Core and called from EmSys.Ui.Wpf.Core.

## Upgrade notes

- `ICtnServices` has a new member. A class of your own that implements the interface must implement `PostMeta_CtnTagAdd`.
