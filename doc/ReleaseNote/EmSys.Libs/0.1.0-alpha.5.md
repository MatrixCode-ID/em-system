# EmSys.Libs 0.1.0-alpha.5

Date: 2026-10-07
Previous: 0.1.0-alpha.4

## Summary
Adds shared contracts for deploying registry images to Docker servers, including target configuration, connection tests, deployment history, and rollback. Shared API contracts and helpers now have expanded English XML documentation for IntelliSense.

## Breaking changes

- `ICtnServices` has new deployment methods. Custom implementations and test doubles must implement them; applications using the supplied backend and WPF services should upgrade those packages together.

## New features

- Deployment DTOs and enums describe SSH and Portainer targets, Stack and standalone Container modes, credentials, tag filters, connection test results, pushed images, and deployment runs.
- `ICtnServices` adds target management, connection testing, Portainer registry registration, stack templates and creation, deployment after push, manual deployment, history, and rollback. The matching implementations are in `EmSys.Api.Core` and `EmSys.Ui.Wpf.Core`.

## Usage notes

- The package now generates an XML documentation file, with expanded English documentation for shared models, service contracts, attributes, and helpers. Assembly and namespace names remain `Em.*`.
