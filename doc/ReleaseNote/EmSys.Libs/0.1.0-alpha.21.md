# EmSys.Libs 0.1.0-alpha.21

Date: 2026-11-14
Previous: 0.1.0-alpha.20

## Summary
Add the renderer-neutral engine of the new document controls (grid model, spreadsheet and word-processing engines, documents and PDF, XLSX, DOCX and CSV writers), so a server can build and write documents without WPF. Add the contracts and models for Business Module Manager positions, contact attachments, attendance setup and product setup.

## New features

- Document engine, synced from the MatrixGrid project: the grid model in `Em.Controls.Grid`, the spreadsheet engine in `Em.Controls.Sheet.*` (including `SheetSession`), the word-processing engine in `Em.Controls.Write.*` (including `WriteSession`), value editors and editing in `Em.Editors` and `Em.Editing`, and document layout and writers in `Em.Documents.*`. The WPF controls that render them are in the new package `EmSys.Ui.Wpf.Controls`.
- The Noto Sans font is embedded for document layout, so documents render the same on every host.
- Positions: `ITenantPositionServices` with copy from another tenant (`TenantPositionCopy`); the employee position is now a reference to a position.
- Contact attachments: `IContactAttachmentServices`, `ContactAttachmentInfo`, `ContactAttachmentUpload` and `ContactAttachmentKind`.
- Contact save: `ContactSave` for the transactional save of a contact with its communications and addresses.
- Attendance setup: `ITenantSchedSettingServices`, `ITenantSchedTemplateServices`, `ITenantAttCodeServices` and `IPublicHolidayServices`, with their models, data sets (`TenantSchedSettingSave`, `TenantSchedTemplateSet`, `TenantSchedEffective`, `TenantAttCodeCopy`, `PublicHolidayCopyResult`) and enums (`TenantSchedMode`, `TenantSchedEnable`, `TenantSchedBuiltIn`, `TenantAttCodeCategory`, `PublicHolidayKind`).
- Product setup: `IUnitServices`, `ITenantProductTypeServices` and `ITenantProductServices`, with batch, copy and search models and the `ProductKind` and `TenantProductSystem` enums.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.21` together. No new NuGet dependency.
- Third-party notices for the ported document code and the bundled fonts are in `THIRD-PARTY-NOTICES.md` and `licenses/` inside the package.
- Guides: `doc/engine/engine-documents.md` and `doc/engine/engine-business-module-manager.md`.
