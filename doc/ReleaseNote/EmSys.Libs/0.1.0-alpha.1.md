# EmSys.Libs 0.1.0-alpha.1

Tanggal: 2026-10-06
Sebelumnya: —

## Ringkasan
Rilis pertama `EmSys.Libs` di nuget.org: kontrak dan utilitas bersama yang dipakai backend (`EmSys.Api.Core`) maupun UI (`EmSys.Ui.Core`, `EmSys.Ui.Wpf.Core`). Ini rilis alpha; API masih bisa berubah tanpa pemberitahuan di versi berikutnya.

## Isi paket
- Model bersama, interface layanan, dan tipe hasil yang dipakai di kedua sisi API dan UI.
- Kontrak layanan untuk fitur engine: user dan role, robot, approval, container registry, NuPak (NuGet server), serta pengaturan storage.
- Identifier UI bersama untuk navigasi dan claim.
- Hashing string dengan Argon2.

## Catatan pemakaian
- Target `net10.0`, tanpa dependensi ke paket `EmSys.*` lain.
- Namespace tetap `Em.Libs` (dan `Em.Api.Core.Models` untuk model inti), berbeda dari nama paket `EmSys.Libs`.
- Pasang dengan `dotnet package add EmSys.Libs --prerelease`.
