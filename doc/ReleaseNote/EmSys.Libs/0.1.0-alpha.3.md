# EmSys.Libs 0.1.0-alpha.3

Date: 2026-10-06
Previous: 0.1.0-alpha.2

## Summary
The container registry service contract gains garbage collection and tag/manifest deletion. Manifest info now reports how many blobs are missing from the server's storage.

## Breaking changes
- `ICtnServices` has four new members: `PostMeta_CtnTagDelete`, `PostMeta_CtnManifestDelete`, `GetMeta_CtnGcReview`, and `PostGetMeta_CtnGcRun`. Classes that implement this interface themselves must add them; code that only calls the service is not affected.

## New features
- `CtnGcReport` and `CtnGcBlob`: the result of a garbage collection review (dry run) or run, with orphaned blobs, stale uploads, files without metadata, sizes, and warnings.
- Constants `ICtnServices.GcDefaultGraceHours` (24) and `GcMaxGraceHours` (720) for the grace period.
- `CtnManifestInfo.BlobCount` and `MissingBlobCount` to identify images whose blob files are missing.
