# EmSys.Libs 0.1.0-alpha.7

Date: 2026-10-08
Previous: 0.1.0-alpha.6

## Summary
Adds `AppVersion`, which reads the product version of the running application for display, and a contract action that tells a debug caller whether the built-in administrator account is switched on.

## New features

- `Em.Shared.AppVersion` reads the informational version of the entry assembly. `Current` gives the version without build metadata, `Display` gives `v1.3.0-alpha.1` or `dev` for a build that keeps the default `0.0.0-dev`, and `TryFromTag` reads a release or container tag such as `v1.3.0-alpha.1` as a version (floating tags such as `latest` are not versions). The status bar of `EmSys.Ui.Wpf.Core` and the publisher use it.
- `ICredentialServices.GetMeta_AdminAccountEnabled()` tells whether the built-in administrator account is switched on. Only a caller with the debug token gets an answer; any other caller receives 404, as if the action did not exist. It is implemented by `EmSys.Api.Core` and used by Switch User in `EmSys.Ui.Wpf.Core`.

## Upgrade notes

- A class that implements `ICredentialServices` itself must add `GetMeta_AdminAccountEnabled()`. The client services in `EmSys.Ui.Wpf.Core` and `EmSys.Ui.Maui.Core` already do.
- To show a real version, set `<Version>` in the host project (or pass `-p:Version` from the release pipeline). See [build.md](../../engine/build.md#product-version).
