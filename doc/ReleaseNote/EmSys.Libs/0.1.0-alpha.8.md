# EmSys.Libs 0.1.0-alpha.8

Date: 2026-10-09
Previous: 0.1.0-alpha.7

## Summary
Adds the contracts for the new SMTP engine: ISmtpService for sending through the default SMTP configuration and ISmtpProfileService for managing and sending through named SMTP profiles, together with their request and result models.

## New features

- `ISmtpService` (module `Administrative Tools`) with the claims `SMTP Manager Access` (configuration and diagnostics) and `SMTP Send` (application email over HTTP). Actions: `GetMeta_SmtpSettings`, `PostGetMeta_SmtpSettingsSave`, `PostGetMeta_SmtpTestConnection`, `PostGetMeta_SmtpTestEmail` and `PostGetMeta_SmtpSend`, plus the `SendAsync(SmtpMessage)` entry point for modules. These work against the default profile.
- `ISmtpProfileService` for named profiles: `GetMeta_SmtpProfiles`, `PostGetMeta_SmtpProfileSave`, `PostGetMeta_SmtpProfileDelete`, `PostGetMeta_SmtpDefault` (set or clear the default), `PostGetMeta_SmtpProfileTestConnection`, `PostGetMeta_SmtpProfileTestEmail`, `PostGetMeta_SmtpProfileTestEmailFrom` (explicit sender), `PostGetMeta_SmtpSendByName` and `SendByNameAsync(name, message)`.
- Models: `SmtpSettings`, `SmtpSecurity` (STARTTLS required, TLS on connect, plaintext for unauthenticated relays), `SmtpSettingsDetail`, `SmtpSettingsSave`, `SmtpProfileDetail`, `SmtpProfileList`, `SmtpProfileSave`, `SmtpMessage` (To/Cc/Bcc, Reply-To, text and HTML bodies, attachments, optional `FromAddress`/`FromName`), `SmtpAttachment`, `SmtpConnectionResult` and `SmtpSendResult`. Responses never carry passwords, ciphertext or keys.
- ORM model for the SMTP profile store, used by `EmSys.Api.Core`.

## Usage notes

- The sender belongs to the message, not to the SMTP configuration: set `SmtpMessage.FromAddress` (and optionally `FromName`) for every email. See `doc/engine/engine-smtp.md`.
