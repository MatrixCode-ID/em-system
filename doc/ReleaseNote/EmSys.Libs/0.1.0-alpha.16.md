# EmSys.Libs 0.1.0-alpha.16

Date: 2026-10-22
Previous: 0.1.0-alpha.15

## Summary
Contracts for runtime service switches and the runtime CDN file size limit.

## New features

- `IFeatureServiceServices` with `FeatureServiceState(Enabled, CanManage)`: read and save the on/off state of the CDN, NuGet feed, Object Storage and Container Registry services. Implemented by EmSys.Api.Core and called from EmSys.Ui.Wpf.Core.
- `ICdnServices.PostMeta_CdnMaxFileSize` saves the runtime per-file CDN limit (1–1,048,576 MB).
- `ServiceDisabledException` (HTTP 503) reports an internal engine service that its administrator has switched off.

## Upgrade notes

- `ICdnServices` has a new member. A class of your own that implements the interface must implement `PostMeta_CdnMaxFileSize`.
