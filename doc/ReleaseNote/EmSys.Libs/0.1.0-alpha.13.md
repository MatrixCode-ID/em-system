# EmSys.Libs 0.1.0-alpha.13

Date: 2026-10-21
Previous: 0.1.0-alpha.12

## Summary
Replaces the approval contracts with the redesigned Data Approval and System Approval model, and adds contracts for the Business Module Manager (tenants, departments, employees), contact search paging, managed CDN folders and CDN release publishing.

## Breaking changes

- `IApprovalServices` is redesigned. Document-type actions, the PDF and slot-calibration actions, `GetMeta_ApprovalGuard`, `GetMeta_ApprovalRequestsByDoc` and `PostMeta_ApprovalCancel` are removed. Requests are listed with `PostGetMeta_ApprovalRequests(ApprovalQuery)` (now a POST), found by subject with `PostGetMeta_ApprovalRequestsBySubject`, decided one at a time with `PostGetMeta_ApprovalDecide(ApprovalDecision)` and withdrawn with `PostMeta_ApprovalWithdraw`. Implementations and callers must be updated together with EmSys.Api.Core and the UI packages of this release.
- The approval request models changed shape: step signers are replaced by step candidates and signatures, item keys are folded into the item, and the old employee model is removed from the library.
- `ICdnServices` has new recycle-bin, temporary-cleanup and managed-folder actions, and `IContactServices` has `PostGetMeta_ContactSearchPage`. Classes that implement these interfaces must add them; callers are not affected.

## New features

- System Approval actions: `PostGetMeta_ApprovalSystemRequest`, `PostGetMeta_ApprovalSystemReinstate`, `PostMeta_ApprovalSystemVoid` and `PostGetMeta_ApprovalSystemFindByKey`, plus signer settings (`GetMeta_ApprovalSignerSettings` / `PostMeta_ApprovalSignerSettings`), attachments and `GetMeta_ApprovalCapabilities`. Requests carry a sub-summary.
- `ITenantServices`, `ITenantDeptServices` and `ITenantEmpServices` with their models, and `Defaults.BusinessModuleName`.
- `ContactSearchQuery` / `ContactSearchPage`: server-side filtered and paged contact search.
- `ICdnReleaseServices` (claim `Release Manager Access`) for publishing releases into CDN folders owned by an application, and `CdnManagedFolder` with quota information.
