# EmSys.Libs 0.1.0-alpha.20

Date: 2026-11-01
Previous: 0.1.0-alpha.19

## Summary
Add a QR code generator: `IQrCodeService` turns a text into a PNG image with a chosen error correction level, module size, quiet zone and colors. It runs on the server, Windows and Android, and the engine registers it on every host.

## New features

- `IQrCodeService.CreatePng(text, options)` and its implementation `QrCodeService` (`QrCodeService.Default` is the registered instance), built on the managed PNG renderer of QRCoder 1.8.1 (MIT), without `System.Drawing` or native graphics libraries.
- `QrCodeOptions` (defaults: error correction M, 10 pixels per module, quiet zone on, black on white), `QrErrorCorrection` (L, M, Q, H) and `QrColor` (opaque RGB with WCAG luminance).
- Numeric and alphanumeric text is encoded compactly; text outside ISO-8859-1 is encoded as UTF-8 with an ECI marker.
- Invalid input fails clearly: `ArgumentNullException` for `null`, `ArgumentException` for empty text or text too long for the chosen level, `ArgumentOutOfRangeException` for a module size outside 1-100.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.20` together. New dependency: `QRCoder` 1.8.1. No database migration is required. See `doc/engine/engine-qr-code.md`.
