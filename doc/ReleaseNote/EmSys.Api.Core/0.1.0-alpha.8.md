# EmSys.Api.Core 0.1.0-alpha.8

Date: 2026-10-09
Previous: 0.1.0-alpha.7

## Summary
Adds a database-managed SMTP engine with multiple named profiles, enabled by the host with builder.AddSmtp(). Modules send email in process through ISmtpService or ISmtpProfileService, and clients use the same actions over HTTP. A database script must be installed before the engine is enabled.

## New features

- `EmAppBuilder.AddSmtp()` registers `ISmtpService` and `ISmtpProfileService` and declares the claims `SMTP Manager Access` and `SMTP Send`. SMTP is off unless the host calls it.
- Named SMTP profiles stored per core database, with an optional single default. `SendAsync` and the legacy actions use the default; `SendByNameAsync`/`PostGetMeta_SmtpSendByName` pick a profile by name (case-insensitive, empty name means the default). No default returns 409, an unknown name 404 and a disabled profile 409; there is no fallback to another profile.
- Saves are checked against a global revision inside a transaction, so stale edits (including a default switched by someone else) are rejected with 409.
- Passwords are encrypted with AES-256-GCM; the key is stored separately. A null password keeps the stored one, `ClearPassword` removes it.
- Transport uses MailKit 4.17.0: required STARTTLS or TLS on connect with certificate validation and no downgrade, plaintext only for unauthenticated relays, To/Cc/Bcc (Bcc only in the envelope), text/HTML bodies and attachments. Limits: 100 recipients, 20 attachments, 10 MiB of attachments, 2 MiB of body text; timeout 5-120 seconds (default 30) per operation.
- Saving a profile and testing a connection do not need a sender. The sender comes from `SmtpMessage.FromAddress`; a sender saved by an earlier build is only used as a fallback for older clients, and without either a send returns 400.

## Upgrade notes

- New package dependency: `MailKit` 4.17.0.
- Before enabling `AddSmtp()`, run `doc/sqlscript/mssql/tables/050-smtp.sql` (after `010-core.sql`) and then `doc/sqlscript/mssql/views/vi_Smtp.sql`. Both scripts can be run again safely. Without them the SMTP actions return 503.
- A single SMTP configuration saved by a pre-release build is converted on first use into a profile named `default`, keeping its settings and password. Stop older API processes before upgrading.
- Guide: `doc/engine/engine-smtp.md`.
