# EmSys.Api.Core 0.1.0-alpha.17

Date: 2026-10-23
Previous: 0.1.0-alpha.16

## Summary
CDN folder settings control the public listing of each folder, and the CDN gains Rename and Copy. Release folders can turn their public listing off through the release service.

## New features

- Folder settings: each CDN folder can carry a `.meta` file (see `CdnFolderSettings` in EmSys.Libs 0.1.0-alpha.17). It is never listed, counted, archived, recycled or served, checked against the real name on disk. With the public listing off, the folder listing answers 404, its files are served with `X-Robots-Tag: noindex`, and the folder is left out of its parent's public listing; direct links keep working and CDN Manager still lists it. Hidden/shown patterns filter the public listing.
- Settings enter through save, upload, rename and extract of a `.meta` file and through `PostMeta_CdnReleaseFolderSettings`. Managed folders, and folders that contain one, refuse changes from CDN Manager with 409.
- `PostGetMeta_CdnRename` renames a file or folder within its folder; renaming a file to `.meta` turns its content into the folder settings.
- `PostGetMeta_CdnCopy` copies a file or folder, including its folder settings, as a global business task, with status, cancel and clear actions. Missing sources, copying a folder into itself, taken names, managed destinations and a copy still running are refused before the task starts.

## Upgrade notes

- No database update is needed.
- Clients that use folder settings, Rename or Copy (EmSys.Ui.Wpf.Core 0.1.0-alpha.17) need this API version; earlier APIs answer 404.
