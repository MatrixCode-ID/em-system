# EmSys.Api.Core 0.1.0-alpha.21

Date: 2026-11-14
Previous: 0.1.0-alpha.20

## Summary
The engine now runs on SQL Server and MySQL through one SQL dialect per provider. The Business Module Manager gains positions, head of department, contact attachments, attendance setup and product setup services, and object storage listing no longer skips or repeats keys.

## Breaking changes

- Saving an employee no longer refuses a person without a default communication or address, on create or update. Hosts that need these details must check them in their own UI; a default that does not belong to the contact is still refused.
- The employee position is a reference to a tenant position instead of free text. Run the update script below on an existing database.
- The old product tables of the business script are removed; product setup has its own script. The update script drops them from an existing installation only when they are empty.

## New features

- SQL Server and MySQL: row locks, schema checks and connection string rules go through a provider dialect, and unique conflicts and missing tables are recognized for every provider. Data Approval follows the core database and refuses mixed providers at startup. SQL Server statements are unchanged.
- Positions per tenant with copy from another tenant, the department head, and the contact full name from the Employee Editor.
- Contact attachments stored in the contact-attachments bucket of object storage.
- `PostGetMeta_Contact_Save` saves a contact with its communications and addresses in one transaction; `GetVi_TenantEmp_ById` reads one employee.
- Attendance setup services under the Business Module Manager claim: scheduling settings with their effective result, schedule templates, attendance codes and public holidays, with audit kinds.
- Product setup services: units (global), product types and products per tenant, with codes unique per tenant, a fixed parent, a kind locked once a type has products, and a system product type and product created for every tenant.

## Fixes

- Object storage listing skips keys at or before the cursor and keeps processing a batch after grouping a common prefix, so pages no longer miss or repeat entries.
- Attendance setup changes are tracked and saved.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.21` together.
- New installation: run `doc/sqlscript/mssql/tables/` in order, now including `110-attendance.sql` and `120-product.sql`, then the new views. MySQL scripts are in `doc/sqlscript/mysql/`.
- Existing installation: run `doc/sqlscript/mssql/updates/20261107-TenantPosition.sql`, `20261112-Unit-Stamp.sql` and `20261112-DropLegacyProduct.sql` (MySQL: the same names under `doc/sqlscript/mysql/updates/`), then `110-attendance.sql`, `120-product.sql` and the new views.
- Guide: `doc/engine/engine-business-module-manager.md`.
