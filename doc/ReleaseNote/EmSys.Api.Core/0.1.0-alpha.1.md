# EmSys.Api.Core 0.1.0-alpha.1

Tanggal: 2026-10-06
Sebelumnya: —

## Ringkasan
Rilis pertama `EmSys.Api.Core` di nuget.org: inti sisi server engine EmSys untuk membangun host API di atas ASP.NET Core. Ini rilis alpha; API masih bisa berubah tanpa pemberitahuan di versi berikutnya.

## Isi paket
- Registrasi layanan, routing action berbasis atribut (`[GetAction]`, `[PostAction]`), dan otorisasi berbasis claim.
- Autentikasi user dan sesi, termasuk debug token opsional (`AddDebugToken`).
- Akses database untuk Microsoft SQL Server, MySQL, dan PostgreSQL, termasuk koneksi database tambahan (`AddExtraDbConn`).
- Fitur engine yang dinyalakan host lewat builder:
  - approval data dan dokumen dengan penyimpanan biner lokal (`AddLocalBinaryStorage`);
  - container registry kompatibel OCI di jalur `/v2` (`AddContainerRegistry`);
  - NuGet server NuPak (`AddNuPak`);
  - pengaturan storage CDN dan registry yang dikelola dari UI (`AddManagedStorageSettings`);
  - endpoint publik dan akses robot untuk modul (`AddPublicEndpoint`).

## Catatan upgrade
- Database baru disiapkan dengan skrip SQL berurutan di `doc/sqlscript/mssql/` pada repo sumber (lihat README repo). Fitur yang dinyalakan host membutuhkan skrip fiturnya masing-masing.
- Host membaca konfigurasi dari `emapi-config.json`; contoh ada di repo sumber (`src/backend/Em.Api/emapi-config.example.json`).

## Catatan pemakaian
- Target `net10.0` dengan shared framework ASP.NET Core. Bergantung pada `EmSys.Libs` versi yang sama.
- Namespace tetap `Em.Api.Core`, berbeda dari nama paket `EmSys.Api.Core`.
- Paket ini library; host HTTP (`Em.Api`) tidak dirilis sebagai paket.
- Pasang dengan `dotnet package add EmSys.Api.Core --prerelease`.
