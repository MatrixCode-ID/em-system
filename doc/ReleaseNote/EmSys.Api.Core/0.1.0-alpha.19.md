# EmSys.Api.Core 0.1.0-alpha.19

Date: 2026-10-30
Previous: 0.1.0-alpha.18

## Summary
Add the backend for the paged user list query used by User Manager: search, state/role/admin/deleted filters, sorting and paging run on the server, and the response includes the roles each listed user holds in effect now.

## New features

- `PostGetMeta_UserListPage` (contract in `EmSys.Libs`) runs search, filtering, sorting and paging in a single call under the existing user-management access. Roles in effect are evaluated against the server clock with the same assignment period rules used for claim loading, and are returned only for the rows on the requested page.
- A page beyond the last record returns an empty row set together with the correct total count.

## Upgrade notes

- Deploy this backend before using the new User Manager from `EmSys.Ui.Wpf.Core` or `EmSys.Ui.Maui.Core` `0.1.0-alpha.19`; older backends do not provide the action.
- No database migration is required relative to `0.1.0-alpha.18`.
