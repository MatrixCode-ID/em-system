# EmSys.Api.Core 0.1.0-alpha.20

Date: 2026-11-01
Previous: 0.1.0-alpha.19

## Summary
The server registers the new QR code generator (`IQrCodeService` from EmSys.Libs) in its service provider, so backend modules can create QR images, for example for reports. No HTTP action is added.

## New features

- `IQrCodeService` is registered as a singleton with the other built-in core services; no host code is needed.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.20` together. No database migration is required. See `doc/engine/engine-qr-code.md`.
