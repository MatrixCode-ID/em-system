# EmSys.Api.Core 0.1.0-alpha.7

Date: 2026-10-08
Previous: 0.1.0-alpha.6

## Summary
Adds the `GetMeta_AdminAccountEnabled` action, which tells a debug token caller whether the built-in administrator account is switched on, so Switch User in the WPF client can hide the administrator card when the account is off.

## New features

- `GetMeta_AdminAccountEnabled` on the credential services (contract in `EmSys.Libs`). It answers only requests made with the debug token; every other caller receives 404 with the same message as an unknown action, so the login screen still does not reveal whether the administrator account is switched off.

## Upgrade notes

- No database migration is required for this release.
