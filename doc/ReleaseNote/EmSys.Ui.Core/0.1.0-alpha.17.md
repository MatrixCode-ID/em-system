# EmSys.Ui.Core 0.1.0-alpha.17

Date: 2026-10-23
Previous: 0.1.0-alpha.16

## Summary
While debug is active, the debug token is sent through every connection, including stored connection profiles, because it identifies the debug build rather than a sign-in.

## Fixes

- `ApiConnection.DebugToken` is set on stored connections too, so a debug build no longer signs in as the debugger account without a token on them. The token is still never written to the Registry.
