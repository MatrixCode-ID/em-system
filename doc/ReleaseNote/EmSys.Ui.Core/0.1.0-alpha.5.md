# EmSys.Ui.Core 0.1.0-alpha.5

Date: 2026-10-07
Previous: 0.1.0-alpha.4

## Summary
Adds module declaration checks for navigation and POST overloads with a per-call timeout for long-running server actions such as container deployment. The package now generates XML documentation for IntelliSense.

## New features

- `NavigationAccess.IsDeclared` checks whether a navigation's required claim, or its module when no claim is required, exists in the claim catalog. Navigation without a module remains available. WPF and MAUI use this check after loading server claims, including for administrators and debug mode.
- `ApiClient.PostAsync` and protected `ServiceUiBase.PostAsync` overloads accept a `TimeSpan` timeout, with generic and non-generic variants. They preserve the existing POST argument format and report expiration as `TimeoutException`.

## Usage notes

- A client timeout does not guarantee that server work has stopped. Check the server-side result before retrying an operation that changes state.
