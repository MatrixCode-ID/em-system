# EmSys.Ui.Core 0.1.0-alpha.21

Date: 2026-11-14
Previous: 0.1.0-alpha.20

## Summary
Add client proxies and UI models for the new Business Module Manager services (positions, contact attachments, attendance setup and product setup), and one shared menu order for WPF and MAUI.

## New features

- Client services for positions, contact attachments, scheduling settings, schedule templates, attendance codes, public holidays, units, product types and products, registered by the WPF and MAUI cores.
- `TenantEmp` and `TenantProduct` UI models: wrapper modules derive from them to lift their own fields out of the extension data.
- `MenuOrder` sorts menu items by order index, then title, and groups by caption.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.21` together.
