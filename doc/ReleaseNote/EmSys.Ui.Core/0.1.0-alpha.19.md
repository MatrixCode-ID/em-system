# EmSys.Ui.Core 0.1.0-alpha.19

Date: 2026-10-30
Previous: 0.1.0-alpha.18

## Summary
Extend the shared `User` client model so screens can work with the paged user list query introduced in `EmSys.Libs` and served by `EmSys.Api.Core`.

## New features

- The `User` client model carries the roles in effect returned by the user list query, so WPF and MAUI user lists can show role information without additional requests.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.19` together. No database migration is required relative to `0.1.0-alpha.18`.
