# EmSys.Ui.Core 0.1.0-alpha.16

Date: 2026-10-22
Previous: 0.1.0-alpha.15

## Summary
Storage manager screens follow the features the active server actually offers.

## Fixes

- `NavigationAccess.MergeClaimCatalogs` merges the client's built-in claims with the server catalog. After the server catalog is loaded, the CDN, NuGet, Object Storage and Container Manager claims stay available only when the server declares them, also for administrators, so a feature the host did not add has no menu entry.

## Upgrade notes

- Connect to an API on EmSys.Api.Core 0.1.0-alpha.16 or later: earlier APIs do not declare the Container Manager claims, so the Container Manager is hidden.
