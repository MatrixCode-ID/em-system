# EmSys.Ui.Core 0.1.0-alpha.1

Tanggal: 2026-10-06
Sebelumnya: —

## Ringkasan
Rilis pertama `EmSys.Ui.Core` di nuget.org: fondasi UI lintas platform dan klien API untuk aplikasi EmSys. Paket UI desktop (`EmSys.Ui.Wpf.Core`) dibangun di atas paket ini. Ini rilis alpha; API masih bisa berubah tanpa pemberitahuan di versi berikutnya.

## Isi paket
- Klien API dan pengelolaan sesi ke server EmSys, termasuk pemilihan koneksi aktif saat login.
- Kontrak navigasi dan logika navigasi yang memperhitungkan claim user.
- Model UI bersama.
- Tema terang/gelap dan branding aplikasi (`ThemeBase`, `BrandingInfo`), termasuk pilihan gaya login.

## Catatan pemakaian
- Target `net10.0`, tanpa ketergantungan ke WPF atau MAUI. Bergantung pada `EmSys.Libs` versi yang sama.
- Namespace tetap `Em.Ui.Core`, berbeda dari nama paket `EmSys.Ui.Core`.
- Paket UI MAUI (`EmSys.Ui.Maui.Core`) belum dirilis di versi ini.
- Pasang dengan `dotnet package add EmSys.Ui.Core --prerelease`.
