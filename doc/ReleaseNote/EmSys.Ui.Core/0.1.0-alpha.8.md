# EmSys.Ui.Core 0.1.0-alpha.8

Date: 2026-10-09
Previous: 0.1.0-alpha.7

## Summary
Adds SmtpClientService and SmtpProfileClientService, shared HTTP proxies for the SMTP contracts in EmSys.Libs that follow the active API connection. WPF and MAUI register them automatically.

## New features

- `SmtpClientService` implements `ISmtpService` and `SmtpProfileClientService` implements `ISmtpProfileService` (module `Administrative Tools`). Both take the API client of the current connection on each call, so they keep working after the user switches server. Requires a server with `AddSmtp()` from `EmSys.Api.Core`.
