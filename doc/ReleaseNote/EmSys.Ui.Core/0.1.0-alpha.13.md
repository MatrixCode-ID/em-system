# EmSys.Ui.Core 0.1.0-alpha.13

Date: 2026-10-21
Previous: 0.1.0-alpha.12

## Summary
Follows the approval redesign on the client side and adds client proxies for tenants, departments and employees.

## Breaking changes

- The approval panel extension points (`ApprovalPanelRegistry`, `IApprovalPanelHost`, `IApprovalPanelInput`) are removed. Modules register a System Approval editor with `ApprovalEditorRegistry` and `IEmApprovalSystemEditor`. `ApprovalManagerNavigationPayload` changed with the new request model.

## New features

- `TenantClientService`, `TenantDeptClientService` and `TenantEmpClientService` implementing the new EmSys.Libs tenant contracts.
