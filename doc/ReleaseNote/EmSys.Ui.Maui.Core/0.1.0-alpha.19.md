# EmSys.Ui.Maui.Core 0.1.0-alpha.19

Date: 2026-10-30
Previous: 0.1.0-alpha.18

## Summary
Refresh the MAUI shell experience: semantic fields, feedback and design tokens, native icon actions with reduced-motion support, a separate My Tasks panel beside a searchable virtual module catalogue with device pins, and accessible login, account and approval layouts. Fix navigation loading, approval connection recovery, text editing in fields, a crash in Home drag buttons, and the caller identity sent after simulated sign-in.

## Breaking changes

- `IconButton` now derives from the native MAUI `Button` instead of `ContentView`. `Glyph`, `TintColor`, `IconSize`, `Command` and `CommandParameter` remain available, but code that relied on `ContentView` members (for example `Content`) must be updated.
- Home no longer shows My Tasks or falls back to all modules when nothing is pinned. It shows only the destinations pinned for the current account and server, the My Tasks summary card, and access to the full catalogue. Older hide/order preferences do not hide or reorder the new catalogue.

## New features

- New shared controls and styles: `MaterialField` (label, icon, supporting/error text and password visibility), `FeedbackView` and `UiFeedback`, `WorkspaceTab`, `HoldDragButton`, `BatchResultPanel`, `FontIcons`, `MotionPolicy`, plus typography, dimension, card, navigation and approval styles (`Styles/Approval.xaml`).
- `MotionPolicy` animates modal entry/exit and horizontal page transitions (forward from the right, Back/Home from the left), respects Android animation scale zero and cancels safely when the destination changes or the shell is disposed.
- My Tasks opens in its own panel (`MyTasksPanel`), with a cached summary card on Home that can be moved before or after the pinned list with tap-hold and drag; the position is stored per account and server.
- The module catalogue is a grouped virtual list with search, icons, collapsible groups and an anchored popover menu (Open, Pin/Unpin to home). Bottom navigation is Home, All Modules, My Tasks.
- Home uses a compact header with the greeting and account name beside an outlined Modules action.
- Login, the account drawer and the approval viewer use the shared palette with permanent labels, grouped review sections and a fixed decision area.
- `IReloadAfterNavigation` marks a navigation body that configures in `OnNavigatingIn` and loads through `OnReloadRequested` after mounting, including when returning to an existing entry.
- Client proxy for `PostGetMeta_UserListPage` (contract in `EmSys.Libs`, backend in `EmSys.Api.Core`).

## Fixes

- Approval screens load after they are mounted on new and existing navigation entries, My Tasks refreshes are not duplicated, opening progress is shown, Android `WebException` is handled and the empty state stays hidden while loading.
- Editing text in `MaterialField` no longer triggers a full presentation update, so Backspace and deleting the last character no longer write the value back into the editor.
- Home drag buttons validate the native peer and handler before cancelling gestures, preventing a crash when switching to the catalogue.
- After a simulated sign-in, cached API clients are refreshed before the session profile loads, so requests no longer carry a stale debugger identity.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.19` together. No database migration is required relative to `0.1.0-alpha.18`.
- Review screens that subclass or inspect `IconButton`, and modules that relied on Home listing all modules without pins. See `doc/engine/engine-maui-experience.md`.
