# EmSys.Ui.Maui.Core 0.1.0-alpha.21

Date: 2026-11-14
Previous: 0.1.0-alpha.20

## Summary
Pinned Home destinations can be reordered with a held drag, navigation bodies can adjust the shell presentation, and Android Escape no longer reaches the shell before focused editors and scanners.

## New features

- Home pins: hold and drag a pin up or down, bounded by the first and last pin; the order is saved per account and server, and new pins are added at the end. `HoldDragButton` gains a list mode (`ReorderIndex`, `ReorderCount`, `ReorderItem`, `ReorderCommand`).
- `INavigationPresentation` lets a navigation body ask for a compact app bar, a custom title and subtitle, or a hidden bottom navigation; stale updates after switching entries are discarded.
- Home and All Modules sort items by order index, then title, with groups alphabetical; pinning no longer reorders the catalogue.
- Client proxies for positions, contact attachments, attendance setup and product setup are registered.

## Fixes

- Releasing a dragged pin no longer flashes the old order.
- Android Escape is handled through an unhandled-key listener, so focused editors and scanners process keys first.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.21` together. Guide: `doc/engine/engine-maui-experience.md`.
