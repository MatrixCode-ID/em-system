# EmSys.Ui.Maui.Core 0.1.0-alpha.2

Tanggal: 2026-10-06
Sebelumnya: —

## Ringkasan
Rilis pertama `EmSys.Ui.Maui.Core` di nuget.org: komponen UI .NET MAUI untuk aplikasi Android EmSys, padanan `EmSys.Ui.Wpf.Core` untuk desktop. Paket ini tidak ikut rilis `0.1.0-alpha.1` dan langsung terbit di versi yang sama dengan paket EmSys lainnya. Ini rilis alpha; API masih bisa berubah tanpa pemberitahuan di versi berikutnya.

## Isi paket
- Host aplikasi MAUI: builder aplikasi dan navigasi satu halaman (SPA) berbasis claim user.
- Layar login, akun, dan ganti password, termasuk pemilihan koneksi server.
- Klien layanan engine untuk approval, business task, kontak, dan kredensial.
- Kontrol ikon dan style Material bersama dengan tema terang/gelap serta branding aplikasi.
- Penyimpanan sesi lewat MAUI `SecureStorage`.

## Catatan pemakaian
- Target `net10.0-android` (Android API 21 ke atas). Bergantung pada `EmSys.Libs` dan `EmSys.Ui.Core` versi yang sama.
- Project pemakai wajib memasang `<UseMaui>true</UseMaui>` dan mereferensikan `Microsoft.Maui.Controls` sendiri, sesuai aturan .NET MAUI SDK.
- Namespace tetap `Em.Ui.Maui.Core`, berbeda dari nama paket `EmSys.Ui.Maui.Core`.
- Pasang dengan `dotnet package add EmSys.Ui.Maui.Core --prerelease`.
