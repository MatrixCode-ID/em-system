# EmSys.Ui.Maui.Core 0.1.0-alpha.20

Date: 2026-11-01
Previous: 0.1.0-alpha.19

## Summary
Show QR codes on Android: the engine registers `IQrCodeService`, `QrCodeImage` turns a text into an `ImageSource`, and the themed `QrCodeView` control draws a scannable code in light and dark themes, mirroring the WPF core.

## New features

- `IQrCodeService` is registered by the engine in every MAUI host; resolve it from `EmApp.ServiceProvider`.
- `Em.Ui.Maui.Shared.QrCodeImage`: `Create(text, options, service)`, `FromPng(png)` and `ToQrColor(color, fallback)`.
- `Em.Ui.Maui.Controls.QrCodeView` with `Text`, `Size` (default 160) and `ErrorCorrection` (default M). Colors come from the palette `surface` and `onSurface` roles; the lighter one is always the tile and quiet zone, so the code stays dark on light in a dark theme. The image is drawn for the display density and redrawn on theme changes; text that cannot be encoded shows an empty tile with the reason in `Error`.

## Upgrade notes

- Update all EmSys packages to `0.1.0-alpha.20` together. No database migration is required. See `doc/engine/engine-qr-code.md`.
