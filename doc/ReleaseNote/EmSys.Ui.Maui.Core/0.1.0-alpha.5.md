# EmSys.Ui.Maui.Core 0.1.0-alpha.5

Date: 2026-10-07
Previous: 0.1.0-alpha.4

## Summary
MAUI navigation now follows the server's declared modules and required claims after the server claim catalog loads, including for administrators and debug mode. The package now generates XML documentation for IntelliSense.

## Breaking changes

- Navigation whose module or required claim is absent from the loaded claim catalog is hidden and cannot be opened. Debug mode still bypasses user permission checks, but no longer bypasses this module declaration check.

## Upgrade notes

- Hosts must declare the modules and claims used by their navigation. Navigation without a module remains available; declaration checks start only after server claims have loaded.
- Upgrade `EmSys.Ui.Core` together with this package; it supplies `NavigationAccess.IsDeclared`.
